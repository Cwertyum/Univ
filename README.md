# 🤖 Многофункциональный Discord Бот

Высокопроизводительный, оптимизированный Discord-бот на **Node.js** и **discord.js v14** с локальной базой данных **SQLite** (WAL mode + RAM-кэш).

---

## ⚡ Особенности и Модули

1. **🛡️ Модерация и Авто-мод**:
   - `/mod warn` / `/mod unwarn` / `/mod warns` — выдача, снятие и просмотр истории варнов.
   - `/mod mute` / `/mod unmute` — мут (таймаут) с автоматическим снятием.
   - `/mod clear` — быстрая очистка сообщений в канале.
   - `/mod automod` — фильтрация мата/плохих слов, ссылок, КАПСА и спама с автоматическим начислением варнов.
   - **Журнал Аудита (Логи)**: `/util audit-setup` — автоматическое логирование нарушений, банов, выходов и модерации.

2. **🔊 Динамические Голосовые Каналы**:
   - `/util voice-hub` — установка канала "Зайти и создать".
   - Участник заходит в хаб → Бот автоматически создает личную комнату и переносит его.
   - Панель управления на кнопках в чате комнаты: 🔒 Замок, ✏️ Изменение имени, 👥 Лимит мест, 🚫 Кик из комнаты.
   - Автоматическое удаление комнаты, когда все участники вышли.

3. **🎫 Система Тикетов**:
   - `/ticket-setup` — отправка красивой панели тикетов с меню выбора темы (Вопрос, Жалоба, Техподдержка, Донат).
   - Интерактивное управление: Закрытие с подтверждением, вызов администрации, скачивание файла транскрипта (`.txt`) и оценка работы поддержки от 1 до 5 звезд.

4. **📈 Уровни и Активность**:
   - `/rank` — просмотр уровня, текущего опыта (XP), прогресс-бара, баланса и репутации.
   - `/leaderboard` — топ-10 самых активных участников сервера.
   - `/rep` — выдача репутации другим игрокам.
   - Начисление опыта за сообщения в чате (с кулдауном от спама) и за нахождение в голосовых каналах.
   - Автоматическая выдача ролей за достижение уровней.

5. **💰 Экономика и Игры**:
   - `/eco balance` — просмотр баланса монет.
   - `/eco daily` — получение ежедневной награды монет.
   - `/eco pay` — перевод монет между участниками.
   - `/eco shop` / `/eco buy` / `/eco add-item` — магазин покупных ролей.
   - `/games coinflip` — игра в Орел и Решка на монеты.
   - `/games guess` — угадай число от 1 до 5.
   - `/games trivia` — викторина с кнопками ответов за награду.

6. **🎉 Розыгрыши и Утилиты**:
   - `/util embed` — отправка красивых Embed карточек с выбором цвета в любой канал.
   - `/util poll` — голосования с реакциями.
   - `/util remind` — установка личных напоминаний (напр. `/util remind 15m Проверить духовку`).
   - `/util giveaway` — запуск конкурсов с таймером и кнопкой участия.
   - `/util afk` — установка AFK-статуса с автоответом при упоминании.

7. **🎵 Музыка**:
   - `/music play` / `/music stop` / `/music skip` / `/music queue` — прослушивание музыки в голосовых каналах.

## 🚀 Как запустить бота

1. Убедитесь, что у вас установлен **Node.js v18+**.
2. Откройте файл `.env` и вставьте ваш токен бота из **Discord Developer Portal**:
   ```env
   DISCORD_TOKEN=ваш_токен_здесь
   ```
3. Для запуска бота выполните команду:
   ```bash
   npm start
   ```
4. Для разработки с автоперезагрузкой:
   ```bash
   npm run dev
   ```

В разделе **Bot** Developer Portal включите следующие **Privileged Gateway Intents**:
- `PRESENCE INTENT`
- `SERVER MEMBERS INTENT`
- `MESSAGE CONTENT INTENT`
